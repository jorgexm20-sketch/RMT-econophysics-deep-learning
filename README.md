# Random Matrix Theory & Deep Learning for Econophysics

This repository contains coursework, computational exercises, and projects developed as part of the course **Quantitative Modern Tools: RMT and Deep Learning in Econophysics/Econometrics**, offered within *Temas Selectos de Física Matemática y Teórica* at the Faculty of Sciences, UNAM.

The repository explores modern quantitative methods for the analysis of complex systems and high-dimensional data, with particular emphasis on financial and economic time series.

Topics include:

Random Matrix Theory (RMT) and Wishart matrices
Correlation matrices and multivariate time-series analysis
Statistical analysis of financial market correlations
Clustering and correlation-based methods
Neural networks
Deep learning for time-series analysis
Applications to econophysics and econometrics

Most of the computational work is implemented in **Python** and focuses on connecting concepts from statistical physics, probability, linear algebra, and machine learning with real-world data analysis.
